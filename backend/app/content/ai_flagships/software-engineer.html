The longer answer for software engineers

Software engineering is not going away, but it is changing faster than most jobs. The tools now write a lot of the routine code — the simple pages, the setup work, the first draft of a test. That is real, and it is why the job feels different than it did two years ago.

What the tools still cannot do is decide what to build, hold a messy system in their head, or answer for it when something breaks at 2am. Those are the parts companies keep hiring for. Across the roughly 3,300 fast-growing companies we track, most software engineer openings still ask first for judgment and system skills, with AI skills showing up as a fast-growing extra rather than the main thing.

So the honest read: fewer people needed for the simple parts, more value on the hard parts. If you write code for a living, the smart move is to get good at the work the tools are bad at — designing systems, catching subtle bugs, and deciding what is worth building in the first place.
